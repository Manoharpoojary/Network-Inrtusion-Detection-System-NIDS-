## Project Description

This project is an **IoT Network Intrusion Detection System** that uses machine-learning models to identify whether network traffic is **normal or anomalous**. It captures live network packets, aggregates them into communication flows, extracts 19 traffic features, and applies trained models such as Random Forest, XGBoost, ANN, and LSTM for intrusion classification.

The system includes:

- **Data preprocessing:** Cleans and prepares IoT network intrusion datasets.
- **Feature engineering:** Extracts protocol, port, packet count, packet length, flow duration, inter-arrival time, and TCP flag features.
- **Model training and comparison:** Evaluates multiple machine-learning and deep-learning models.
- **Live detection:** Captures real-time network traffic using Scapy and generates anomaly predictions.
- **Web dashboard:** Uses Streamlit to display captured flows, predictions, anomaly probabilities, and traffic summaries.
- **Feature validation:** The `analyze_feature_groups.py` script checks duplicate feature vectors and detects whether identical traffic patterns are associated with multiple classes.
- **Output files:** Stores live features and predictions in CSV files for analysis and visualization.

### Integration Summary

When combining this project with another application, it can be integrated as a **network-security module**. The other project can send traffic-flow data to the prediction component and receive:

```text
Prediction: Normal or Anomaly
P_Anomaly: Probability of anomalous traffic
P_Normal: Probability of normal traffic
```

The main interface is the Streamlit application in `app.py`. The project requires Python packages listed in `requirements.txt`, including Pandas, Scikit-learn, TensorFlow-related model support, Scapy, Joblib, and Streamlit.

**Important:** Although the repository name suggests next-word prediction, the current implementation is focused on **IoT network intrusion detection**, not natural-language prediction.

12. Pkt_Len_Std – Standard deviation of packet lengths.
13. Flow_IAT_Mean – Average time between packets in a flow.
14. Flow_IAT_Std – Variation in time between packets in a flow.
